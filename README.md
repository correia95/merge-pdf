# Merge PDF

Combine multiple PDF files into one, entirely in the browser. React + TypeScript + Vite, deployed
as a static Cloudflare Worker.

- Drag-and-drop or multi-file picker upload
- Per-file page counts, drag rows to reorder
- Built with `pdf-lib`, code-split so it only loads when merging
- Nothing is uploaded

## Dev

```
npm install
npm run dev
npm run build
npm run deploy
```
